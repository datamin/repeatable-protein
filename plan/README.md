# Content plan

This folder converts validated search demand into an executable page roadmap.

## Files

- [`page-roadmap.csv`](page-roadmap.csv) — planned pages and their target clusters.
- [`pillar-page-outline.md`](pillar-page-outline.md) — working story and content order for the first pillar page.

## Planning rules

1. One primary search intent per page.
2. A page may cover several close variants only when the same answer satisfies them.
3. Keyword hypotheses remain `research_pending` until US and India metrics and SERPs are checked.
4. Meal pages should include quantities, protein, calories, preparation time, substitutions, and country-appropriate measurements.
5. Health claims require reliable sources and an appropriate expert review process.
6. Publish the smallest coherent cluster first instead of creating disconnected articles.

## Proposed first cluster

The first publishable cluster should center on the repeatable-protein method:

- One pillar guide explaining the system.
- A US vegetarian meal-plan implementation.
- An Indian vegetarian/eggetarian implementation.
- Supporting breakfast and lunch pages.
- A calculator/planner that turns the method into an action.

This is provisional until keyword and SERP validation is complete.
