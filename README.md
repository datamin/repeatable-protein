# Strong on Repeat

Research and execution workspace for a static content website about helping busy women meet an appropriate protein target with fewer daily food decisions.

The working editorial idea is simple: calculate a repeatable breakfast and lunch once, rotate only when useful, and leave dinner flexible. The example `85 + 15` method reaches 100 g of protein, but the site will make clear that individual protein needs vary.

## Repository structure

- [`seo-research/`](seo-research/) — verified keyword clusters, country-level search volume, keyword difficulty, intent, and SERP observations.
- [`plan/`](plan/) — page inventory, cluster-to-page mapping, priorities, briefs, and internal-link plans.
- [`status/`](status/) — publication and performance tracking once pages are live.

## Research markets

- United States
- India

## Data rules

1. Keep US and India metrics in separate rows.
2. Record the source and date for every volume/KD observation.
3. Never replace missing data with an assumption; use `pending`.
4. Map each keyword to one primary page to reduce cannibalization.
5. Treat 100 g as a searchable example, not a universal health recommendation.

## Live website

The static site is published with GitHub Pages at [strongonrepeat.com](https://strongonrepeat.com/). The original repository URL redirects to the custom domain.
